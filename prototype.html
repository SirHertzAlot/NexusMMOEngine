Nexus Editor — prototype shell · Tailwind CSS + shadcn/ui system

Iteration 9 (Joey): the iteration-8 shell rebuilt on Tailwind utilities + the shadcn design system (zinc tokens, Button/Badge/Card patterns, tailwindcss-animate motion: rails slide in, widgets zoom-summon, scene loads flash, provenance ticks in). Now responsive and accessible: rails become slide-in drawers below lg, both bars scroll horizontally, touch targets grow on coarse pointers; landmarks and labelled panels, aria-live provenance and save state, full keyboard operation (tree, props, shelf, component headers, canvas pan/zoom), visible black focus rings, and reduced-motion support. The bar pills are all wired now (session details, server start/stop, module list, provenance history, focus chip, zoom reset), and the IDE terminal drag-resizes, closes, reopens from the nav bar, and detaches/merges like any other panel. Final piece in: the view pane renders real three.js when the CDN is reachable — orbit, zoom, click-to-select, tool drags, and Play walks Mira in 3D through the same live data; offline it falls back to the stand-in render. Every nav and data surface is wired (tools, undo/redo for live edits, step, menus, export). Live decorators added: values that change in real time carry a streaming dot, flash when they change, and are editable in place through the verb layer — press Play and Mira walks, her needs creep, the shrine breathes. The editor backend is node + express (file service, graph, live overlay). Dev controls added: the Designer ⇄ Developer switch (Ctrl+Shift+D) opens IDE mode — project explorer, code editor, a WorldStore data panel, and a terminal with a working graph CLI — the developer surface from the two-surfaces-one-pipeline design, opening on the file your current selection points at. Theme inverted at Joey’s word: black on grey — black ink and primary actions on layered greys.
