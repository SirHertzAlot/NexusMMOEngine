# Documentation

Start with [GETTING-STARTED.md](GETTING-STARTED.md) to run the engine, then
the guides below. [DECISIONS.md](DECISIONS.md) and [ROADMAP.md](ROADMAP.md)
are the running record of what was decided and what is built, in progress,
or planned.
