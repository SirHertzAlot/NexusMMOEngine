# Document Library

Design specs, evaluations, audits, and research reports for the Nexus MMO
Engine, mirrored from Arlo's working document library on 2026-10-27 at
Joey's request — so the full library lives in this repo (and in local
clones) alongside the canonical docs at `docs/` root.

- Organized by the library's original topic folders (`mmo-engine-*`).
- Nothing here overwrites a canonical `docs/` file; where a library
  document shares a name with one (e.g. `ARCHITECTURE.md`,
  `LIVING-SIM-DEEP-DIVE.md`), the library copy is the research-side
  document and the root copy stays canonical.
- The working originals continue to evolve outside the repo; re-mirroring
  is a copy-over on request, not a sync.

Held back from this mirror (available on request): the game-name filing
packet (legal), the local-only mini-demo runbook, and Arlo's PC-access
safety plan (personal infrastructure).
