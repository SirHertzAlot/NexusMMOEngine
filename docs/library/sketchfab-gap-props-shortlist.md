# Sketchfab gap-props shortlist — cook / healer / priest / guard

Scouted 2026-10-17. Fills the four profession gaps left by the fantasy-pack
correction (the Poly by Google collection has zero cauldrons, potions,
altars/chalices, swords, shields, or armor — verified against the full
2,292-model collection).

Filters: downloadable, CC Attribution 4.0 only, ≤5k faces, thumbnails eyeballed
against the polygonal style gate (faceted low-poly, theme-fitting). Downloads
need a free Sketchfab login — same as the other shortlists.

Thumbnail sheet: `sketchfab-gap-props-thumbs.jpg` (labels match the numbers below).
